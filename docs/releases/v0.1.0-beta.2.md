Second beta of Orbit, a radial menu for the selected file or folder, for
macOS (Apple silicon) and Windows (x64).

## What changed since 0.1.0-beta.1

- **Choosing an action is easier.** After the pointer moves away from the
  point where the menu opened, the direction from the menu center decides,
  at any distance: the pointer no longer has to stay inside the ring.
  Releasing outside the ring now performs the action it points to. To
  dismiss the menu, release in the center or over **Cancel**, or press Esc.
  Releasing without moving still does nothing.
- **Folder sizes on macOS are faster and closer to the disk.** Info counts a
  folder or package with several threads: about five times faster than
  before. The size is now the space the items take on the disk, like
  `du -x`, not the sum of their lengths, so a sparse disk image no longer
  makes a folder look larger than the disk.
- **iCloud Drive is not downloaded.** Counting a folder with iCloud items
  that are not on this Mac used to hang while iCloud fetched them. Orbit now
  skips such items and shows the size as "At least …".

## Use

1. Select one file or folder in Finder (macOS) or File Explorer (Windows).
2. Hold **Ctrl+Option+Space** (macOS) or **Ctrl+Alt+Space** (Windows). The
   menu opens at the pointer. Keep the shortcut held.
3. Move toward an action and release the shortcut. Esc, the center or
   **Cancel** dismisses the menu.

Working actions on both systems:

- **Copy path** copies the full path of the item.
- **Info** shows the path, the kind of item and its size (on Windows,
  for files only).
- **Reveal** opens the enclosing folder with the item selected.

Rename, ZIP, Resize and image conversion are not ready yet. On Windows
they are dimmed; on macOS they do not perform an operation.

## Install on macOS

1. Download `Orbit-0.1.0-beta.2-macos-arm64.zip`, unpack it and move
   `Orbit.app` to Applications. It runs on Apple silicon only.
2. Open Orbit. The app is ad-hoc signed and not notarized, so macOS blocks
   the first launch. Open **System Settings → Privacy & Security**, click
   **Open Anyway** next to the message about Orbit and confirm.
3. Allow Orbit in **Privacy & Security → Accessibility** when asked. The
   menu starts working without a restart.
4. Quit from the Orbit icon in the menu bar. The log is in
   `~/Library/Logs/Orbit/orbit.log`.

## Install on Windows

1. Download `Orbit-0.1.0-beta.2-windows-x64.zip`, unpack it and run
   `orbit.exe`. No installer and no Visual C++ Redistributable are needed.
2. The exe is not signed, so Microsoft Defender SmartScreen may warn about
   it. If it does, choose **More info → Run anyway**.
3. Exit from the Orbit icon in the notification area. The log is in
   `%LOCALAPPDATA%\Orbit\Logs\orbit.log`.

## Known limitations

- The new way of choosing an action has passed the automated tests but has
  not yet been tried by hand on either system.
- The Windows build has passed the automated tests on Windows but has not
  yet been tried by hand. See `docs/windows.md` for its limitations and the
  manual check list; reports are welcome.
- Ctrl+Alt acts as AltGr on many European keyboard layouts, so the Windows
  shortcut can clash with a character there.
- macOS: Apple silicon only. Builds are ad-hoc signed and the bundle
  identifier is still a placeholder (`com.example.orbit`), so after an
  update macOS may ask for Accessibility again.
- macOS: the size of a single file is its length, while the size of a
  folder is the space on the disk, so the two can differ for a sparse file.
  Counting a folder on a slow network volume can take long to stop.
